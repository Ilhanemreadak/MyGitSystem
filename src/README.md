# MyGitSystem

MyGitSystem, bir dosya yönetimi ve sürüm kontrol sistemi uygulamasıdır. Bu proje, Visual Studio Code kullanılarak geliştirilmiştir.

## Kurulum

1. **Visual Studio Code** yükleyin.
2. **Git** yükleyin.
3. **Bash terminali** açın.
4. **Proje klonlayın:** `git clone https://github.com/Ilhanemreadak/MyGitSystem.git`
5. **Klonlanan projeye gidin:** `cd MyGitSystem`
6. **Başlatmak için Visual Studio Code'yi açın:** `code .`

## Kullanım

### Komutlar

- `git add .`: Değişiklikleri staging alanına alır.
- `git commit -m "Commit mesajı"`: Staging alındaki değişiklikleri kaydeder.
- `git push origin main`: Yerel değişiklikleri uzak depoya gönderir.

### Yapılandırma

Proje yapılandırması dosyası (`mygit/config.json`) içerir. Bu dosya, projenizin genel ayarlarını ve özelliklerini yönetmek için kullanılır.
